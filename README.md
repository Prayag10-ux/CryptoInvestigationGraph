# Evidence-Backed Crypto Investigation Graph

SIH 2026 — SIH26183

## Overview

An automated blockchain investigation system for identifying potential
fraud-linked cryptocurrency exchanges from victim-reported suspect wallet
addresses.

## Core Workflow

Victim Complaint
→ Suspect Wallet
→ Blockchain Analysis
→ Fund-Flow Tracing
→ Fraud Pattern Detection
→ Exchange/VASP Attribution
→ Evidence & Confidence
→ Investigator Report

## MVP Scope

The initial MVP focuses on Ethereum-based wallet investigation.
